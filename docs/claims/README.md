# Ledger klaim (arsip)

Folder ini menyimpan audit dan rencana perbaikan prosa yang dijalankan pada
2026-11-08, sebelum repo berganti nama menjadi Nusapeta Route. Isinya adalah
catatan historis, bukan status sekarang dan bukan dokumentasi penggunaan.

- `audit-001`, `audit-002`: temuan terhadap prosa dan kode saat itu.
- `plan-001`: rencana perbaikan untuk audit 001.

Nama berkas, binary (`rid-*`), dan temuan di dalamnya sengaja tidak diperbarui:
itu bukti apa yang ditemukan pada commit tersebut. Padanan nama sekarang ada di
`paper/README.md`. Status pekerjaan yang masih terbuka ada di `docs/BACKLOG.md`.
